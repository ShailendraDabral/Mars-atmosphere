# Changelog

## [1.0.0] — 2026-10-20

First public release.

- `marspinn` Python package and CLI implementing the full protocol: QC and physics audit, profile-level splits,
  gap scenarios, twelve reconstruction methods, validation tuning, E1–E4 experiments, conformal calibration,
  bootstrap CIs and Holm-corrected paired tests.
- Reported results on 185 MRO RSS profiles (`results/`), with the executed Kaggle notebook.
- Interactive browser simulator of the workflow (`docs/`, GitHub Pages).
- Processed MRO RSS dataset (`data/processed/`) and the builder script for the PDS products.
